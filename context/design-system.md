# City Travels - Design System

## Brand Identity
- **Name**: City Travels
- **Vibe**: Professional, Warm, Adventurous, Trustworthy.

## Color Palette (Proposed)
- **Primary**: Ocean Blue (`#006994`) - Trust, Calm.
- **Secondary**: Sunset Orange (`#FF7F50`) - Energy, Warmth (Accents/Buttons).
- **Background**: White / Light Gray (`#F8F9FA`).
- **Text**: Dark Slate (`#333333`).

## Typography
- **Headings**: 'Montserrat' or 'Poppins' (Modern, clean sans-serif).
- **Body**: 'Open Sans' or 'Roboto' (Readable).

## UI Elements
- **Buttons**: Rounded corners, clear hover states.
- **Cards**: Soft shadows (`box-shadow: 0 4px 6px rgba(0,0,0,0.1)`), clean white background.
- **Images**: High-quality, real photography (no generic 3D clipart).

## Responsiveness
- **Breakpoints**: Standard Bootstrap breakpoints.
- **Mobile First**: Design for 360px width first, then expand.
