# City Travels - Project Context

## 1. Project Overview
**City Travels** is a travel agency specializing in domestic customized travel packages for families, couples, small groups, and commercial clients.
**Goal:** Build an MVP website to establish brand credibility and generate leads via WhatsApp and phone.
